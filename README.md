# 智云人才培养平台 - 自动刷课助手

油猴脚本，自动播放视频、滚动文档、跳转下一节，支持倍速和静音。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 新建脚本，将 `auto-course-helper.user.js` 内容粘贴保存
3. 访问智云平台课程页面即可使用

## 功能

- **视频自动播放** - 自动静音、倍速播放，播完自动跳转下一节
- **文档自动滚动** - 自动滚动到底部，完成后自动跳转
- **附件自动跳过** - 检测到附件页面自动跳过
- **倍速选择** - 支持 1x / 1.25x / 1.5x / 2x / 4x / 8x / 16x
- **可拖拽控制面板** - 右下角浮动面板，可拖动位置
- **手动启停** - 默认不自动执行，点击「开始自动学习」才启动
- **暂停恢复** - 暂停后切换页面不会自动继续，视频同步暂停

## 使用方法

1. 进入课程学习页面，右下角出现「自动刷课助手」面板
2. 选择视频倍速
3. 点击「开始自动学习」
4. 脚本自动处理当前资源，完成后自动跳转下一个
5. 需要暂停时点击「暂停」

## 页面识别

| URL 路径 | 类型 | 行为 |
|----------|------|------|
| `/video` | 视频 | 静音倍速播放，播完跳转 |
| `/document` | 文档 | 自动滚动到底部，完成跳转 |
| `/attach` | 附件 | 短暂停留后跳过 |
| `/courses/` | 课程列表 | 无自动操作 |

## 注意事项

- 平台播放器会在视频结束时循环重置进度，脚本通过 `ended` 事件和循环检测双重保障来识别视频结束
- SPA 页面切换不会触发页面刷新，脚本通过轮询 URL 变化来检测导航
- 暂停状态在页面切换间保持，只有再次点击「开始」才会恢复
